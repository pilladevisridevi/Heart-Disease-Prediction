# Heart-Disease-Prediction
Heart Disease Prediction using Machine Learning on the Framingham dataset. This project includes data preprocessing, exploratory data analysis (EDA), feature scaling, and model training using Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine (SVM) to predict the risk of heart disease.
# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Project Overview
This project predicts the risk of heart disease using the Framingham Heart Disease dataset. The project applies data preprocessing, exploratory data analysis (EDA), feature scaling, and multiple machine learning classification algorithms to predict whether a person is at risk of developing heart disease.
## 🎯 Objective
The objective of this project is to build a machine learning model that predicts the likelihood of heart disease based on patient health information and compares the performance of different classification algorithms.
## 📂 Dataset
- **Dataset:** Framingham Heart Disease Dataset
- **Target Variable:** `TenYearCHD`
